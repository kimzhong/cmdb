# CMDB 系统使用手册

## 一、系统概述

CMDB（Configuration Management Database）配置管理数据库系统是一个用于集中管理 IT 基础设施资源的平台。通过本系统，您可以：

- 管理各类 IT 资产（服务器、网络设备、云资源等）
- 建立资源之间的关联关系
- 通过标签对资源进行分类管理
- 自动化同步云资源数据
- 快速检索目标资源

## 三、功能模块使用指南

### 3.1 全局搜索

**位置**：左侧导航栏顶部

**功能**：快速检索系统中的资源

**使用方法**：
1. 在搜索框中输入关键字
2. 系统会返回所有匹配的资源
3. 点击结果可直接跳转到资源详情页

### 3.2 应用视图

**位置**：左侧导航 → 应用视图

**功能**：以业务和应用为核心的资源视图

**使用方法**：

#### 3.2.1 业务管理

1. 点击「业务管理」
2. 点击「新建业务」
3. 填写业务信息：
   - 业务名称：如「电商平台」
   - 唯一标识：如 `ecommerce`（英文字母）
   - 描述：业务描述
   - 负责人：负责人用户名

#### 3.2.2 应用管理

1. 选择一个业务
2. 点击「新建应用」
3. 填写应用信息：
   - 应用名称：如「用户中心」
   - 唯一标识：如 `user-center`
   - 负责人：负责人
   - 状态：planning/developing/testing/running/stopped

#### 3.2.3 应用关联资源

在应用详情页面，可以关联：
- 主机资源
- 域名
- 中间件
- 数据库

可通过标签筛选不同环境（测试/预发/生产）的资源。

### 3.3 资源模型

**位置**：左侧导航 → 资源模型

用于定义资源的数据结构。

#### 3.3.1 模型管理

**功能**：管理资源模型

**操作步骤**：

1. **创建模型分组**
   - 点击「模型管理」
   - 点击「新建分组」
   - 选择分类（资产模型/应用模型/组织模型/其他）
   - 填写分组名称和唯一标识

2. **创建模型**
   - 选择一个分组
   - 点击「新建模型」
   - 填写模型信息：
     - 模型名称：如「云主机」
     - 唯一标识：如 `instance`
     - 描述：模型描述

3. **创建字段分组**
   - 进入模型详情
   - 点击「添加字段分组」
   - 填写分组名称：如「基本属性」

4. **创建字段**
   - 点击「添加字段」
   - 填写字段信息：
     - 字段名称：如「主机名」
     - 唯一标识：如 `instance_name`
     - 字段类型：选择适当类型
     - 是否必填：根据需要设置

**字段类型说明**：

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| string | 字符串 | 名称、描述等文本 |
| number | 数字 | IP、端口等数值 |
| date | 日期 | 创建时间、到期时间 |
| select | 下拉选项 | 状态、类型等枚举值 |
| password | 密码 | 需加密存储的敏感信息 |
| relation | 关系 | 关联其他模型 |

#### 3.3.2 关系管理

**功能**：定义模型之间的关系

**关系类型**：

1. **从属关系 (belong)**
   - 一对一关系
   - 示例：主机从属于子网

2. **连接关系 (connect)**
   - 多对多关系
   - 示例：主机关联安全组

**操作步骤**：
1. 进入模型详情
2. 点击「添加关系」
3. 选择关系类型和目标模型
4. 设置基数（one-to-one/one-to-many/many-to-many）

### 3.4 资源仓库

**位置**：左侧导航 → 资源仓库

**功能**：管理和查看资源数据

#### 3.4.1 浏览资源

1. 选择资源分类
2. 选择模型分组
3. 选择具体模型
4. 查看资源列表

#### 3.4.2 创建资源

1. 进入资源列表页面
2. 点击「新建」
3. 根据字段定义填写资源信息
4. 点击「保存」

#### 3.4.3 编辑资源

1. 在资源列表中点击目标资源
2. 点击「编辑」
3. 修改资源信息
4. 点击「保存」

#### 3.4.4 管理关系

在资源详情页面，可以：
- 查看从属关系
- 查看连接关系
- 添加/移除关联资源

#### 3.4.5 关联标签

1. 在资源详情页面
2. 找到「标签」区域
3. 点击「添加标签」
4. 选择标签值

### 3.5 标签管理

**位置**：左侧导航 → 标签管理

**功能**：管理资源的标签体系

#### 3.5.1 创建标签键

1. 点击「标签管理」
2. 点击「新建标签键」
3. 填写标签信息：
   - 标签名称：如「环境」
   - 唯一标识：如 `environment`
   - 描述：标签描述

#### 3.5.2 创建标签值

1. 进入标签键详情
2. 点击「新建标签值」
3. 填写标签值：如 `test`（测试环境）、`pre`（预发环境）、`prod`（生产环境）

#### 3.5.3 绑定资源

1. 进入标签值详情
2. 点击「绑定资源」
3. 选择模型
4. 选择要绑定的资源

### 3.6 定时任务

**位置**：左侧导航 → 定时任务

**功能**：自动同步云资源数据

#### 3.6.1 创建任务

1. 点击「定时任务」
2. 点击「新建任务」
3. 填写任务信息：
   - 任务名称：如「同步阿里云主机」
   - 唯一标识：如 `sync_aliyun_instance`
   - 同步模型：选择目标模型
   - 云类型：cloud/other
   - 同步类型：full（全量）/incremental（增量）
   - 定时策略：Cron 表达式

**常用 Cron 表达式**：

| 表达式 | 说明 |
|--------|------|
| `0 0 * * *` | 每天凌晨执行 |
| `0 */6 * * *` | 每6小时执行 |
| `0 0 * * 0` | 每周日凌晨执行 |

#### 3.6.2 管理任务

- 查看任务执行状态
- 启用/停用任务
- 编辑任务配置
- 删除任务

## 四、用户管理

### 4.1 查看用户列表

系统管理员可以查看所有用户。

### 4.2 创建用户

1. 点击用户管理入口
2. 点击「新建用户」
3. 填写用户信息：
   - 用户名
   - 密码
   - 昵称
   - 邮箱
   - 电话
   - 角色

### 4.3 LDAP/AD 集成

如需集成 LDAP 或 AD：

1. 编辑 `config.yaml` 配置 LDAP 参数
2. 设置 `ldap.enabled: true`
3. 用户登录时使用 LDAP 账号

## 五、最佳实践

### 5.1 模型设计流程

```
1. 梳理资源 → 2. 梳理字段 → 3. 评估创建 → 4. 平台上建立模型
```

**示例：创建「云主机」模型**

1. **基本信息**
   - 名称：云主机
   - 唯一标识：instance

2. **基本属性字段**
   - 唯一标识(instance_identify)
   - 名称(instance_name)
   - 内网IP(instance_private_ip)
   - 公网IP(instance_public_ip)
   - 实例规格(instance_type)
   - 状态(instance_status)

3. **关系属性**
   - 从属：所属可用区
   - 连接：关联安全组

### 5.2 资源维护流程

1. 在模型管理中创建模型
2. 在资源仓库中添加资源数据
3. 根据需要关联标签
4. 通过应用视图管理业务和应用

### 5.3 环境管理

使用标签实现环境管理：

```
标签键：environment（环境标识）
├─ test（测试环境）
├─ pre（预发环境）
└─ prod（生产环境）
```

在应用视图中，可通过标签筛选不同环境的资源。

## 六、常见问题

### Q1: 如何修改密码？

1. 点击右上角用户名
2. 选择「修改密码」
3. 输入旧密码和新密码
4. 点击保存

### Q2: 如何导出资源数据？

在资源列表页面，支持导出功能（需开发扩展）。

### Q3: 为什么无法删除模型？

为保护数据安全，删除模型前需确保：
- 模型下没有资源数据
- 模型下没有字段
- 模型下没有关系定义

### Q4: 如何备份数据？

MongoDB 数据备份：
```bash
mongodump -d cmdb -o /backup/
```

### Q5: 如何重启服务？

```bash
# 停止服务
pkill cmdb

# 启动服务
./cmdb-server &
```
