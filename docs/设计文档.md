# CMDB 系统设计文档

## 一、项目概述

### 1.1 项目背景

CMDB（Configuration Management Database）配置管理数据库是运维自动化平台的核心基础设施。本系统旨在帮助运维团队集中管理各类 IT 资产，建立资源之间的关联关系，实现基础设施的标准化、自动化管理。

### 1.2 项目目标

1. **资源统一管理** - 将分散的服务器、网络设备、应用系统等资源进行集中管理
2. **关系可视化** - 建立资源之间的关联关系，通过图形化方式展示资源拓扑
3. **数据自动化** - 通过定时任务自动同步云资源数据，减少人工维护成本
4. **查询便捷化** - 提供全局搜索能力，快速定位资源信息

## 三、功能模块设计

### 3.1 认证授权模块

#### 3.1.1 用户认证

- **本地认证** - 用户名密码登录，密码使用 bcrypt 加密
- **LDAP/AD 认证** - 支持 LDAP 目录服务集成
- **JWT Token** - 基于 JWT 的无状态认证

#### 3.1.2 权限控制

- **角色** - 管理员(admin) / 普通用户(user)
- **管理员** - 全部权限
- **普通用户** - 基于模型的读写权限

### 3.2 模型管理模块

#### 3.2.1 模型分组

- 创建/编辑/删除模型分组
- 支持分类：资产模型、应用模型、组织模型、其他
- 内置分组不可删除

#### 3.2.2 模型管理

- 创建/编辑/删除模型
- 模型基本信息维护
- 支持启用/停用

#### 3.2.3 字段管理

- 创建/编辑/删除字段
- 支持字段类型：
  - **string** - 字符串
  - **number** - 数字
  - **date** - 日期
  - **select** - 下拉选项
  - **password** - 密码（加密存储）
  - **relation** - 关系（关联其他模型）

#### 3.2.4 关系管理

- 定义模型之间的关系
- **从属关系(belong)** - 一对一关系，如主机从属于子网
- **连接关系(connect)** - 多对多关系，如主机关联安全组

### 3.3 资源管理模块

#### 3.3.1 资源浏览

- 按模型分组展示资源
- 支持列表/详情视图
- 支持多条件搜索

#### 3.3.2 资源操作

- 创建/编辑/删除资源
- 维护资源关系
- 关联标签

### 3.4 标签管理模块

#### 3.4.1 标签键管理

- 创建/编辑/删除标签键
- 标签键全局唯一

#### 3.4.2 标签值管理

- 创建/编辑/删除标签值
- 绑定/解绑资源

### 3.5 定时任务模块

#### 3.5.1 任务管理

- 创建/编辑/删除同步任务
- 配置 Cron 表达式
- 支持全量/增量同步

#### 3.5.2 任务执行

- 记录执行日志
- 记录上次执行时间

### 3.6 应用视图模块

#### 3.6.1 业务管理

- 创建/编辑/删除业务
- 业务层级维护

#### 3.6.2 应用管理

- 创建/编辑/删除应用
- 应用生命周期管理（planning → developing → testing → running → stopped）
- 应用关联资源

### 3.7 全局搜索模块

- 支持关键字全文检索
- 返回匹配的资源列表

## 五、配置说明

### 5.1 配置文件结构

```yaml
# config.yaml

# 服务器配置
server:
  host: 0.0.0.0
  port: 8080

# MongoDB 配置
mongodb:
  host: localhost
  port: 27017
  database: cmdb
  username: ""
  password: ""

# LDAP/AD 配置
ldap:
  enabled: false
  host: ""
  port: 389
  base_dn: ""
  user_dn: ""
  password: ""
  use_ssl: false
  ad:
    enabled: false
    domain: ""
    base_dn: ""

# JWT 配置
jwt:
  secret: "cmdb-secret-key-change-in-production"
  expire: 24h

# 日志配置
log:
  level: info
  file: logs/cmdb.log
```

### 5.2 环境变量

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| PORT | 服务端口 | 8080 |
| MONGODB_URI | MongoDB 连接地址 | mongodb://localhost:27017 |
| JWT_SECRET | JWT 密钥 | - |

### 6.2 生产部署建议

1. **Web 服务器** - 使用 Nginx 反向代理
2. **HTTPS** - 配置 SSL 证书
3. **MongoDB 副本集** - 建议至少 3 节点
4. **日志收集** - 接入 ELK/Loki
5. **监控** - 接入 Prometheus + Grafana

## 七、安全考虑

1. **密码安全** - 使用 bcrypt 加密存储
2. **传输安全** - 生产环境使用 HTTPS
3. **JWT 过期** - 设置合理的 Token 过期时间
4. **输入验证** - 前后端双重验证
5. **SQL 注入** - 使用 MongoDB 参数化查询
6. **CORS** - 配置允许的跨域来源
